# Changelog

- First release: `schema.prisma` and `*.prisma` files in a read-only offline inspector, parsed locally in plain JavaScript with zero Prisma CLI or database calls.
- Datasource, generator, model, enum, view and composite type explorer, visual model-relationship table, index and unique constraint viewer, and static schema findings (unindexed foreign keys, cascade-delete hazards, plaintext datasource URLs, missing `@id`, deprecated `previewFeatures`).
