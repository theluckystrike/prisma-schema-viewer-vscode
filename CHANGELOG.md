# Changelog

## 0.1.0

- Offline custom editor and inspector for `schema.prisma` and `*.prisma` files.
- Datasource, generator, model, enum, view and composite type explorer with search, kind filter and detail pane.
- Visual model-relationship table with cardinality, foreign-key columns, `onDelete` actions and index coverage.
- Index and unique constraint inventory (`@id`, `@@id`, `@unique`, `@@unique`, `@@index`).
- Static schema findings for unindexed foreign keys, cascade-delete hazards, plaintext datasource URLs, missing `@id` and deprecated `previewFeatures`.
- Click-only Zovo Pro tools (1 free try each): Markdown schema audit, schema diff and Mermaid ERD + CSV dictionary export.
